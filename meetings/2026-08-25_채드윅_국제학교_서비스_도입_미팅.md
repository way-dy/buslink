## 한 줄 요약
채드윅 국제학교 서비스 관련 기존 개선 요청사항 진행 상황을 확인하고, 승객용 앱의 운행 정보 표시 오류 및 슬리핑 차일드 기능 개선에 대한 요청사항을 논의했습니다.

## 핵심 논의
*   기존 개선 요청사항 처리 현황 및 추가 확인
*   승객용 앱에서 운행 정보 표시 오류 (시간 변경, 경로 이탈) 현상 논의
*   슬리핑 차일드 기능 관련 현황 및 관리자 페이지 기능 개선 요청

## 고객 요청사항
1.  **승객용 앱 운행 상태 표시 오류 수정**:
    *   앱 화면을 내렸다가 다시 올리면 버스 도착 시간이 실제 도착 시간(현재 시각)으로 변경되는 현상 수정 — [01:19] "처음 내려오면 시간이 이렇게 되는데 한 번 내려왔다가 다시 올라오면은 시간이 도착 시간으로 바뀌는 현상이 있어요."
    *   운행 종료 후 시간이 지나면 운행 완료된 경로(회색)가 파란색으로 다시 활성화되는 현상 수정. 특히 운행 종료 후 기사가 다른 위치로 이동했을 때 발생 — [02:16] "이게 시간 어느 이상을 벗어나면은 그냥 갑자기 튀어 버려요. 여기 노선도 이제 파란색이 있는 이유가 이제 점점 회색으로 변해 가면서 따라가는 건데 어 다 도착한 이후에 갑자기 이전에 있던 게 사라지면서 어 기사가 예를 들면 뭐 한 운행이 끝나고 저기 밑에 판교 쪽에 가 있으면은 없어져요. 그 갑자기 또 파란색으로 뜨고"
2.  **슬리핑 차일드 관리자 페이지 기능 개선**:
    *   슬리핑 차일드 태그를 찍은 내역(언제/어디서 찍었는지)을 관리자 화면에서 확인할 수 있도록 추가 — [03:51] "이게 기서 블로 대시보드에 뜨긴 하는데 이 내역 좀 언제 찍었고 어디 찍었고 요런 내역 좀 제가 볼 수 있고"
    *   슬리핑 차일드 기능 관리 페이지에서 특정 노선(예: 하교 노선)만 선택하여 볼 수 있도록 필터링 기능 추가 — [04:36] "하교 거는 하교 때만 좀 이제 제가 볼 수 있고 관리를 할 수 있는 페이지 하나 만들어 주시면"

## 결정 사항
1.  **개선 요청서 내용 즉시 확인 및 처리**: 시스템 관리자가 제출한 개선 요청서 내용을 즉시 확인하고 처리하기로 함. — [00:35] "이거는 내가 바로 해 주지."
2.  **슬리핑 차일드 현황 관리자 화면 추가**: 슬리핑 차일드 태그 기록 현황을 관리자 화면에 추가하기로 결정. — [04:00] "아 당연히 있어야지. 그거 그 저기 관리자 화면에 넣어 줄게. 슬리핑 차일드 현황."
3.  **슬리핑 차일드 관련 관리자 화면 추가 개발**: 슬리핑 차일드 기능을 운영하는 노선만 선택하여 관리할 수 있는 페이지를 추가 개발하기로 함. — [04:56] "오케이 알았어."

## 개발 참고사항
*   **기존 개선 요청사항**: 이전에 시스템 관리자가 게시판에 올린 개선 요청서 내용이 있음. (구체적인 내용은 본 회의에서 다시 설명됨) — [00:10] "개선 요청 사항 있었는데", [00:38] "어제 올렸어요.", [01:05] "개선 요청상에 제가 적어 놨었어요."
*   **승객용 앱 운행 시간 표시 문제**: 처음 앱 화면 로딩 시에는 정상적인 시간이 표시되나, 화면을 아래로 내렸다가 다시 올리면 버스의 '도착 시간'으로 변경되는 현상이 발생함. 이는 시간이 고정되어야 하는 부분임. — [01:19] "처음 내려오면 시간이 이렇게 되는데 한 번 내려왔다가 다시 올라오면은 시간이 도착 시간으로 바뀌는 현상이 있어요."
*   **승객용 앱 경로 표시 문제**: 운행이 종료되고 모든 경로가 회색으로 바뀌었음에도 불구하고, 일정 시간이 지나면 이전 운행 경로의 일부가 파란색으로 다시 표시되는 현상이 발생함. 특히 운행이 끝나고 차량이 다른 위치(예: 판교)로 이동했을 때 발생하며, 이는 운행 완료 상태가 유지되어야 함. — [02:16] "이게 시간 어느 이상을 벗어나면은 그냥 갑자기 튀어 버려요. 여기 노선도 이제 파란색이 있는 이유가 이제 점점 회색으로 변해 가면서 따라가는 건데 어 다 도착한 이후에 갑자기 이전에 있던 게 사라지면서 어 기사가 예를 들면 뭐 한 운행이 끝나고 저기 밑에 판교 쪽에 가 있으면은 없어져요. 그 갑자기 또 파란색으로 뜨고"
*   **슬리핑 차일드 기능 관련**:
    *   현재 기사 앱 대시보드에서는 슬리핑 차일드 태그가 찍힌 것이 확인되나, 상세 내역(언제, 어디서 찍었는지)은 관리자가 확인할 수 없음. — [03:51] "이게 기서 블로 대시보드에 뜨긴 하는데 이 내역 좀 언제 찍었고 어디 찍었고 요런 내역 좀 제가 볼 수 있고"
    *   슬리핑 차일드 기능은 주로 하교 시에 사용되므로, 관련 관리 페이지에서 하교 노선 등 특정 노선만 필터링하여 관리할 수 있는 기능이 필요함. — [04:36] "하교 거는 하교 때만 좀 이제 제가 볼 수 있고 관리를 할 수 있는 페이지 하나 만들어 주시면", [04:55] "보통 하교 때 하니까."
    *   기존 어드민 화면에 슬리핑 차일드 관련 기능이 있을 가능성이 언급됨. — [04:11] "아 내가 어둠이 화면에 넣어 놓는 거 같은데."
