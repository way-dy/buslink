# 그룹(관리회사) 설정 — 기초 설계 초안 (2026-07-16 회의 #4, way 검토용)

> 상태: **초안 — way 확정 전 구현 금지**. 회의 결정: "노선·차량·바코드 세팅은 그룹 단위 통합,
> 탑승자 관리·협력사 어드민·탑승 현황은 서브 회사별 분리. 정의랑 팩트가 일치해야 한다."
> 사례: 다우디지털스퀘어(그룹) ← 다우기술·와이즈·한국 3개 입주사가 같은 버스·노선 공유.

## 현재 구조와 갭
- `routes.partnerCode` 가 **단일 거래처**에 묶임 → 공유 노선을 한 거래처에만 걸면
  다른 입주사 직원앱(노선탭 partner 필터, 2026-07-09 Phase 2)에서 안 보임.
  버스인처럼 한 거래처에 억지로 묶으면 탑승 현황에 타사 직원까지 노출(회의 지적).
- 반면 **탑승자·탑승현황·통계는 이미 `partnerCode` 필드로 격리**되어 있음
  (passengers/boardings/fcmTokens/포탈 쿼리 전부 code 단위) — 분리 요건은 현행 유지로 충족.
  즉 갭은 "노선(차량·바코드 포함) 계층의 공유 개념 부재" 하나다.

## 제안 데이터 모델 (최소 변경)
- 신규 최상위 `partnerGroups/{groupId}`: `{ name, companyId, memberCodes: string[], createdAt, active }`
  — 그룹 정의. 멤버=기존 partnerCodes 문서의 code (기존 협력사 구조 재사용·재발급 불요).
- `routes.groupId`(옵션 신규): 그룹 공유 노선 표식. **`routes.partnerCode` 는 유지**(단독 거래처 노선 하위호환).
- 차량·고정 QR: 변경 0 — 정적 QR 은 이미 차량 단위(`?c&v`)이고 노선은 승객 선택으로 매핑(회의 #1 반영분)이라
  그룹 공유와 자연 호환. 탑승 적재도 승객의 partnerCode 가 자동 기록되므로 서브 분리 유지.

## 가시성 해석 규칙 (소비 지점 4곳)
`visibleRoutes(partnerCode) = (routes.partnerCode == code) ∪ (routes.groupId ∈ groupsOf(code))`
1. 직원앱 노선탭·노선 변경 모달·홈 폴백 필터 (EmployeeApp — 기존 myPartner 게이트 확장)
2. 협력사 포탈 운영 포털(노선 카드·지도·노선도) — 현재 passengers.routeId 파생이라 사실상 이미 동작,
   노선 카드 라벨에 "그룹 공유" 배지만 추가
3. AdminApp 노선 폼: 거래처 선택 대신 **그룹 선택** 옵션(둘 중 하나만)
4. 공지 발송 대상: 그룹 노선 공지 = 멤버 codes 전체 발송(선택 옵션)

## 관리자 UI (회의 언급 반영)
- 협력사 관리 탭에 "그룹" 서브 섹션: 그룹 생성 → 멤버 협력사 **직관적 다중 선택**(회의: "카카오 피커처럼") →
  그룹에서 일괄 변경하면 멤버 전체 반영(=그루핑).
- 인승 제한·예약 등 기존 노선 단위 기능은 그대로(그룹 노선도 노선 문서 1개).

## 단계 제안
- **G1**: partnerGroups 컬렉션 + routes.groupId + 직원앱/포탈 가시성 확장 (핵심·격리 배포 가능)
- **G2**: AdminApp 그룹 관리 UI + 노선 폼 그룹 선택
- **G3**(옵션): 그룹 롤업 통계(그룹 전체 탑승 합산 뷰) · 그룹 단위 공지
- 마이그: 다우디지털스퀘어 그룹 1개 생성 + 입주사 3개 코드 멤버 등록 + 공유 노선 groupId 지정(스크립트 불요·콘솔 수작업 규모)

## 결정 필요 (way)
1. 그룹을 별도 컬렉션(`partnerGroups`, 위 제안)으로 갈지, `partnerCodes` 에 `parentCode` 계층으로 갈지
   — 제안은 별도 컬렉션(정의=팩트 일치·거래처 문서 오염 없음).
2. rules: partnerGroups read 공개(partnerCodes 와 동일) / write isAuth 로 갈지.
3. 포탈 어드민 권한: 그룹 상위 포탈(전 멤버 조망) 계정을 둘지, 서브 코드만 둘지(회의는 서브 분리만 언급).
