BusLink M 시뮬레이션 확인 및 요청사항(2026.06.22)

 승객 노선 변경 기능
• 승객이 기존 배정된 버스가 아닌 다른 버스를 이용해야 하는 경우가 발생할 수 있습니다.
• 이 경우 직원어플 노선탭에서 채드윅 노선만 소팅이 가능한지 여쭤볼 수 이있을까요!

용어 변경 요청

• 현재 “주간조”로 표기되는 부분은 채드윅 운영 특성상 “등교 / 하교” 로 채드윅 거래처만 바꿀 수 있을까요?
• 기존 버스링크 직원 → 버스링크 승객 으로 변경 가능할까요!

사번 및 비밀번호 생성 방식
• 사번 등록 후 관리자가 비밀번호를 변경해야 최종 생성되는 구조로 확인했습니다!
• 반드시 비밀번호 변경 절차를 거쳐야 사번이 생성되는 구조인지 확인 부탁드립니다.

채드윅 계정 조회 범위
• 채드윅의 경우 가정별로 실제 이용자가 부모님, 조부모님, 수행기사 등으로 수시 변경될 가능성이 있습니다.(미팅결과)
• 1가정 1코드 방식으로 운영할 경우 실제 확인자가 달라지는 상황에서 불편이 예상됩니다.
• 따라서 1개 아이디로 전체 노선 조회가 가능한지 확인 부탁드립니다.
• 현재 버스인 관제시스템은 chad5462 라는 아이디로 전체관제 가능

지도 화면 밝기
• 절전모드 또는 시력보호 설정이 켜진 상태에서는 지도 화면이 너무 어둡게 보입니다.
• 실제 학부모 사용 시 위치 확인이 어려울 수 있어 지도 밝기 개선 가능 여부 확인 부탁드립니다.

승객 사번 생성 규칙
• 현재 사번 생성 시 숫자 위주로만 가능한 것으로 보입니다.
• 운영 편의상 숫자와 영문을 혼용한 ID 생성이 가능한지 검토 부탁드립니다.

셔틀 노선 등록 방식
• 셔틀 형태의 노선은 동일 정류장을 반복 운행하는 경우가 있습니다.
• 현재 동일 정류장을 중복 등록하면 최초 도착 시간만 기록되는 것으로 보입니다.
• 이 경우 셔틀 노선을 별도로 2개 생성해야 하는지, 또는 동일 정류장 반복 등록이 가능한 방식이 있는지 확인 부탁드립니다.

뒤로가기 종료 확인 문구
• 앱에서 뒤로가기를 누르면 별도 확인 없이 바로 종료되는 것으로 확인됩니다.
• 사용자가 실수로 앱을 종료할 수 있어, “정말 종료하시겠습니까?”와 같은 확인 문구 삽입이 가능한지 검토 부탁드립니다.

차량 등록 수 제한
• 현재 차량 등록이 1대만 되고 있습니다!

배차관리 등록 내역 사라짐
• 배차관리에 등록한 내역이 일정 시간 후 또는 재접속 시 사라지는 현상이 확인됩니다.
