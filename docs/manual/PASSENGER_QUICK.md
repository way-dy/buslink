# 승객 앱 요약 가이드

통근버스를 이용하는 승객용 앱의 핵심 사용법입니다. 휴대폰에서 사용합니다.

## 1. 접속과 설치

① 휴대폰 브라우저에서 **`p.buslink.co.kr`** 에 접속합니다.
② 매번 주소를 입력하지 않도록 **홈 화면에 추가**(앱 설치)를 권장합니다.

- **아이폰**: 사파리 아래 **공유** 버튼 → **홈 화면에 추가**
- **안드로이드**: 브라우저 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

## 2. 로그인

**사번**과 **PIN** 을 입력하고 **`로그인`** 을 누릅니다. 한 번 로그인하면 이후 자동으로 유지됩니다.

> **첫 로그인 PIN은 `000000`(0 여섯 개)** 입니다. 첫 로그인 후 **설정** 탭에서 PIN을 꼭 변경해 주세요.

## 3. 홈 — 버스 위치와 도착 시각

- 화면 위에 **현재 노선**이 표시됩니다. 다른 노선을 보려면 **`🔄 노선 변경`** 을 누릅니다.
- 노선도에서 **내가 타는 정류장**을 누르면, 버스가 가까워질 때 알림을 받습니다.
- 지도에서 버스가 실시간으로 움직이고, 정류장별 **예상 도착 시각**이 표시됩니다.
- 버스 위치가 갱신되지 않으면 화면 위 **`새로고침`** 을 누릅니다.

## 4. 탑승 — QR 스캔

① 아래 메뉴에서 **`탑승`** 을 누르면 카메라가 켜집니다. (처음 사용 시 카메라 권한 허용)
② **기사님 휴대폰의 QR** 또는 **차량에 부착된 QR** 을 화면 안에 비춥니다.
③ 인식되면 **탑승 완료**로 기록됩니다.

> **내가 선택한 노선의 차량이 아니면 탑승이 되지 않습니다.** 화면에 **"선택한 노선의 차량이 아닙니다"** 안내와 함께 그 차량이 오늘 운행하는 노선이 표시됩니다. 홈에서 노선을 확인·변경한 뒤 다시 스캔해 주세요.

## 5. 공지와 알림

- 아래 메뉴 **`공지`** 에서 운행 관련 공지를 확인합니다. 긴급 공지는 앱을 열 때 전체 화면으로 표시됩니다.
- 알림을 받으려면 앱에서 **알림을 허용**해 주세요. 알림이 오지 않으면 **`설정`** 탭의 **`🔄 알림 재발급`** 을 누릅니다.
