# 승객 앱 요약 가이드

통근버스 승객용 앱의 핵심 사용법입니다. 휴대폰에서 사용합니다.

## 1. 설치와 로그인

<div style="display:flex;gap:6mm;justify-content:center;align-items:flex-start"><img src="assets/employee/01-login.png" style="max-width:38%;margin:3mm 0 2mm" alt="로그인 화면"><img src="assets/employee/02-install-android.png" style="max-width:38%;margin:3mm 0 2mm" alt="앱 설치 안내"></div>

- 휴대폰 브라우저에서 **`p.buslink.co.kr`** 접속 → **사번**과 **PIN** 입력 후 **`로그인`**
- **첫 PIN은 안내문에 적힌 번호** — 사람마다 다릅니다(2026년 7월 이전에 받으신 분만 `000000`)
- 첫 로그인에서 **비밀번호 변경 화면이 반드시 나옵니다**(건너뛸 수 없음) — 받으신 날 바로 바꿔 주세요
- 앱 설치: 앱을 열면 화면 아래에 **설치 안내**가 뜹니다 — **`설치`** 를 누르면 홈 화면에 아이콘이 생깁니다(설치하실 때까지 접속할 때마다 다시 안내합니다)
  - 🔴 **카카오톡에서 링크를 열면 설치가 되지 않습니다** — 안내의 **`인터넷 브라우저로 열기`** 를 먼저 눌러 크롬/사파리로 나간 뒤 설치해 주세요
  - 안내가 안 보이면: 안드로이드는 브라우저 메뉴(⋮) → **앱 설치**(또는 **홈 화면에 추가**), 아이폰은 사파리 **공유** → **홈 화면에 추가**

## 2. 홈 — 버스 위치와 도착 시각

<img src="assets/employee/04-home.png" style="max-width:34%" alt="홈 화면">

- 지도에서 버스가 실시간으로 움직이고, 정류장별 **예상 도착 시각**이 표시됩니다
- 다른 노선을 보려면 **`노선 변경`**, 위치가 안 바뀌면 **`새로고침`**
- 아래 노선도에서 **내가 타는 정류장**을 누르면 버스가 가까워질 때 알림이 옵니다
- 화면 위 빨간 배너가 보이면 **`설정 방법`** 을 눌러 알림을 허용해 주세요

## 3. 탑승 — QR 스캔

아래 메뉴 **`탑승`** → 카메라로 **기사님 휴대폰의 QR** 또는 **차량에 부착된 QR** 을 비추면 **탑승 완료**로 기록됩니다.

> 앱에서 스캔하시면 사번·비밀번호를 다시 넣지 않으셔도 됩니다. 휴대폰 기본 카메라로 차량 QR을 찍어 여신 경우에는 **사번과 비밀번호**로 본인 확인을 한 번 하시며, 그 뒤로는 그 휴대폰에서 버튼 한 번으로 탑승됩니다.

> **출근·퇴근 두 번 다 찍으셔도 됩니다.** 같은 차량이어도 노선이 다르면 각각 기록됩니다. 같은 노선을 두 번 찍었을 때만 **"오늘 이 노선 탑승은 이미 기록되어 있습니다"** 가 뜹니다.

> **선택한 노선의 차량이 아니면 탑승이 되지 않습니다.** **"선택한 노선의 차량이 아닙니다"** 안내가 뜨면, 홈에서 노선을 확인·변경한 뒤 다시 스캔해 주세요.

## 4. 공지 확인

- 아래 메뉴 **`공지`** 에서 운행 관련 안내를 확인합니다. 긴급 공지는 앱을 열 때 전체 화면으로 표시됩니다
