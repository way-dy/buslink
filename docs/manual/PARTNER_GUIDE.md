# 협력사 포탈 요약 가이드

통근버스를 이용하는 회사의 담당자용 포탈입니다. 자사 승객 등록·관리, 운행 확인, 공지 발송을 합니다.

## 1. 접속과 로그인

- 브라우저에서 **`partner.buslink.co.kr`** 접속 → 운영사에서 발급받은 **업체코드** 입력
- 인증되면 4개 탭이 보입니다: **`📋 승객 등록`** · **`👥 승객 관리`** · **`📊 탑승 통계`** · **`🚌 운영 포털`**

> 업체코드가 없거나 만료된 경우 통근버스 운영사 담당자에게 문의하세요.

## 2. 승객 등록 — `📋 승객 등록` 탭

- **`📂 파일 업로드`** — **`📥 엑셀 양식 다운로드`** 로 양식을 받아 명단 작성 후 업로드(여러 명 일괄)
- **`👤 개별 등록`** / **`👥 다중 등록`** — 화면에서 직접 입력해 등록

> 등록된 승객의 **첫 PIN은 `000000`** 입니다. 승객이 앱에서 첫 로그인 후 직접 변경합니다.

## 3. 승객 관리 — `👥 승객 관리` 탭

- 검색창에 **이름·사번·부서** 입력으로 승객 검색
- **`수정`** — 이름·부서·배정 노선 변경 / **`PIN초기화`** — PIN을 `000000` 으로 초기화

## 4. 운영 포털 — `🚌 운영 포털` 탭

- **`🛣 자사 노선`** — 자사 노선 카드. 카드를 누르면 아래 현황이 그 노선만으로 좁혀집니다
- **`📍 실시간 버스 위치`** — 지도에서 운행 중인 버스 위치를 실시간 확인
- **`🚏 차량 운행 현황 (노선도)`** — 정류장 한 줄 노선도. **지나간 정류장 = 파란 ✓**, **버스 현재 위치 = 🚌**
- **`🎫 오늘 탑승 현황`** — 오늘 자사 승객 탑승 인원 요약

> 실시간 버스 위치와 차량 운행 현황(노선도)은 운영사(관리자) 설정에 따라 회사별로 표시되지 않을 수 있습니다.

## 5. 공지 발송과 수신함 — 운영 포털 탭 아래쪽

- **`📢 공지 발송`** — **제목**(50자)·**내용**(500자) 입력, **일반/긴급** 선택 후 발송 → 자사 승객 앱으로 알림
- **`📢 공지사항`** — 운영사·자사가 보낸 공지 수신함

> 공지는 **시간당 5건**까지 발송됩니다. 남은 건수가 화면 오른쪽 위에 표시됩니다.

## 6. 탑승 통계 — `📊 탑승 통계` 탭

- 기간을 지정해 조회하면 자사 승객 탑승 기록을 **일자별·승객별·노선별**로 확인할 수 있습니다
