# 협력사 포탈 요약 가이드

통근버스를 이용하는 회사의 담당자용 포탈입니다. 브라우저에서 **`partner.buslink.co.kr`** 접속 → 운영사에서 발급받은 **업체코드**를 입력하면 4개 탭이 보입니다: **`📋 승객 등록`** · **`👥 승객 관리`** · **`📊 탑승 통계`** · **`🚌 운영 포털`**

## 1. 로그인과 승객 등록

<div style="display:flex;gap:6mm;justify-content:center;align-items:flex-start"><img src="assets/partner/code-login.png" style="max-width:40%;margin:2mm 0" alt="업체코드 로그인"><img src="assets/partner/register.png" style="max-width:34%;margin:2mm 0" alt="승객 등록 탭"></div>

- **업체코드** 입력 → **`인증하기`** (코드가 없으면 운영사 담당자에게 문의)
  - 한 번 인증하면 **그 기기에 30일간 유지**됩니다 — 창을 닫았다 열거나 새로고침해도 업체코드를 다시 입력하지 않습니다. 여러 사람이 쓰는 공용 PC 라면 일을 마친 뒤 **`인증 해제`**(PC 는 왼쪽 아래, 휴대폰은 오른쪽 위)를 눌러 주세요
  - 뒤로가기를 누르면 **보시던 이전 화면**으로 돌아가고, 더 돌아갈 화면이 없을 때만 *포털을 나가시겠습니까?* 를 한 번 여쭙습니다
- **PC 로 보시면 화면이 가로로 넓게** 펼쳐집니다(왼쪽 메뉴 + 넓은 작업 영역). 휴대폰·태블릿은 지금까지와 같은 화면입니다
- **`📋 승객 등록`** — **`📂 파일 업로드`**(엑셀 양식으로 일괄) · **`👤 개별 등록`** · **`👥 다중 등록`**
  - 인원이 많으면 등록하는 동안 **`등록 중... 1,234 / 16,155명`** 처럼 진행 상황이 숫자로 보입니다. 다 끝날 때까지 창을 닫지 마세요
- 등록하면 승객마다 **서로 다른 여섯 자리 첫 비밀번호**가 자동 발급됩니다. 그 번호는 **등록 직후 한 번만** 보이므로 **`📄 안내문 만들기`**로 인쇄해 나눠 주세요(승객은 첫 로그인에서 본인 번호로 바꿉니다)

## 2. 승객 관리와 탑승 통계

<div style="display:flex;gap:6mm;justify-content:center;align-items:flex-start"><img src="assets/partner/manage.png" style="max-width:37%;margin:2mm 0" alt="승객 관리 탭"><img src="assets/partner/stats.png" style="max-width:36%;margin:2mm 0" alt="탑승 통계 탭"></div>

- **`👥 승객 관리`** — 이름·사번·부서 검색, **`수정`**(노선 배정 변경), **`비밀번호 재발급`**
  - 비밀번호는 **사람마다 다른 6자리**가 새로 발급됩니다(공통 번호가 아닙니다). 발급된 번호는 **그 화면에서 한 번만** 보이므로, 창을 닫기 전에 **`📄 안내문 만들기`**로 인쇄해 두세요
  - 인원이 많은 회사는 목록을 **100명씩** 나눠 보여 드립니다. 위쪽 인원 수와 검색은 **전체 기준**이라, 찾으실 분은 이름이나 사번으로 검색하시면 바로 나옵니다
  - PC 에서는 같은 목록이 **표**로 보입니다(이름·사번·부서·노선·상태·NFC 카드). 보시는 내용과 검색 결과는 휴대폰과 같습니다
- **`📊 탑승 통계`** — 기간 지정 조회, 자사 승객 탑승 기록을 일자별·승객별·노선별 누적 확인

## 3. 운영 포털 — 오늘의 운행 한눈에

<img src="assets/partner/ops-routes.png" style="max-width:92%;margin:2mm 0" alt="자사 노선 카드">

- **`🛣 자사 노선`** — 노선 카드를 누르면 아래 지도·현황이 그 노선만으로 좁혀집니다

<img src="assets/partner/ops-map.png" style="max-width:78%;margin:2mm 0" alt="실시간 버스 위치 지도">

- **`등교` · `하교` · `방과후`** — 노선 이름 옆 버튼입니다. 누르면 그 구분의 노선만 남고 아래 지도·노선도도 함께 좁혀집니다. 하교와 방과후하교처럼 시간대가 겹치는 노선을 갈라 볼 때 씁니다(다시 누르면 전체)
- **`📍 실시간 버스 위치`** — 운행 중인 버스가 지도에 실시간 🚌 로 표시됩니다

<img src="assets/partner/ops-strip.png" style="max-width:92%;margin:2mm 0" alt="차량 운행 현황 노선도">

- **`🚏 차량 운행 현황 (노선도)`** — 지나간 정류장은 **파란 ✓**, 버스의 현재 위치는 **🚌** (사진은 운행 대기 상태)

<img src="assets/partner/ops-boarding.png" style="max-width:92%;margin:2mm 0" alt="오늘 탑승 현황">

- **`🎫 오늘 탑승 현황`** — 오늘 자사 승객의 탑승 인원·탑승률 요약

> **`📍 실시간 버스 위치`** 와 **`🚏 노선도`** 는 운영사 설정에 따라 회사별로 표시되지 않을 수 있습니다.

## 4. 공지 발송

<img src="assets/partner/ops-notice-send.png" style="max-width:70%;margin:2mm 0" alt="공지 발송">

- **제목**(50자)·**본문**(500자) 입력, **일반/긴급** 선택 → 자사 승객 앱으로 알림 발송
- **시간당 5건**까지 — 남은 건수가 화면 오른쪽 위에 표시됩니다. 받은 공지는 아래 **`📢 공지사항`** 수신함에서 확인
