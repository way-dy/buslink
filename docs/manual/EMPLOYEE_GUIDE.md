# 직원(승객) 매뉴얼

이 안내서는 통근버스를 이용하는 **직원용 앱(BusLink 직원 탑승 서비스)** 사용법입니다. 휴대폰에서 사용합니다.
내 버스가 언제 오는지 확인하고, 탑승을 기록하고, 공지를 받는 앱입니다.

## 1. 로그인 / 앱 설치

① 휴대폰 브라우저에서 **`p.buslink.co.kr`** 에 접속합니다.
② **사번**과 **PIN** 을 입력하고 **`로그인`** 을 누릅니다.
③ 한 번 로그인하면 다음부터 자동으로 로그인 상태가 유지됩니다.

![직원 로그인 화면](assets/employee/01-login.png)

> **첫 로그인 PIN은 받으신 안내문에 적힌 번호**입니다 — 사람마다 다른 여섯 자리입니다.
> (2026년 7월 이전에 받으신 분만 `000000`(0 여섯 개)을 쓰십니다.)
> 처음 로그인하면 **본인만 아는 번호로 바꾸는 화면이 반드시 나옵니다**(건너뛸 수 없습니다).
> 계정을 받으신 날 바로 로그인해 바꿔 주세요 — 바꾸기 전까지는 다른 사람이 먼저 들어갈 수 있습니다.

**앱 설치(홈 화면에 추가)** — 매번 주소를 입력하지 않도록 설치를 권장합니다.

- **아이폰**: 사파리 아래 **공유** 버튼 → **홈 화면에 추가**
- **안드로이드**: 브라우저 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

![앱 설치 안내](assets/employee/02-install-android.png)

## 2. 홈 — 내 버스 위치와 도착 시각

로그인하면 보이는 첫 화면입니다. **내 정류장에 버스가 언제 오는지**와 **지도 위 버스 위치**를 보여줍니다.

- 화면 위에 내 이름·부서와 현재 노선이 표시됩니다.
- 지도에서 버스가 실시간으로 움직이고, 정류장별 **예상 도착 시각**이 표시됩니다.
- 노선을 바꾸려면 오른쪽 위 **`노선 변경`** 을 누릅니다.

![직원 홈 화면](assets/employee/05-mystop.png)

> 화면 맨 위 파란 띠는 새로 온 **공지**입니다. 내용을 확인하면 닫힙니다.

## 3. 내 정류장 설정 — 도착 임박 알림 받기

내가 타는 정류장을 정해 두면, 버스가 가까워질 때 **도착 임박 알림**을 받습니다.

① 홈 화면 아래 노선도에서 안내 문구 **`아래 노선도에서 내 정류장을 클릭하세요`** 를 따라 내가 타는 정류장을 누릅니다.
② 정류장이 선택되면, 버스가 1~2 정거장 전에 오면 휴대폰으로 알림이 옵니다.

> 알림을 받으려면 앱에서 **알림을 허용**해야 합니다. 알림이 안 오면 아래 **6. 설정**의 알림 진단을 확인하세요.

## 4. 탑승 — QR로 탑승 기록

버스에 탈 때 QR로 탑승을 기록합니다. 노선에 따라 두 방식 중 하나입니다.

- **내 QR을 보여주는 방식**: 아래 메뉴에서 **`탑승`** 을 누르면 내 탑승 QR이 나타납니다. 이 QR을 **기사님께 보여주면** 기록됩니다. (QR은 2분마다 자동 갱신)
- **기사님 QR을 찍는 방식**: 카메라가 켜지면 기사님 휴대폰의 **탑승 QR**을 화면 안에 비춥니다. 인식되면 **탑승 완료**로 기록됩니다. (처음 사용 시 카메라 권한 허용)
- **차량에 부착된 QR을 찍는 방식**: 차량 입구에 붙어 있는 QR을 앱의 `탑승` 탭에서, 또는 **휴대폰 기본 카메라**로 그냥 찍어도 됩니다. 이 경우 **사번과 비밀번호로 본인 확인**을 한 번 거친 뒤 기록됩니다. 한 번 확인하면 그 휴대폰이 기억해 **다음부터는 버튼 한 번**입니다(다른 분이 타실 때는 `다른 사람`을 누르세요).

![탑승 QR 화면](assets/employee/07-scan.png)

> **탑승이 기록되면 짧은 확인음과 진동이 옵니다.** 소리는 `설정` → **태깅 소리**에서 끌 수 있습니다(회사 정책에 따라 끄지 못하는 경우도 있습니다).
> 휴대폰이 **무음 모드**이거나 소리 크기가 0이면 확인음이 나지 않습니다 — 이때도 진동은 옵니다.

## 4-1. 홈페이지 — 회사 안내 보기

**회사(협력사)에 따라** 아래 메뉴에 **`홈페이지`** 가 보일 수 있습니다.

① 아래 메뉴에서 **`홈페이지`** 를 누릅니다.
② **`홈페이지 열기`** 를 누르면 회사 홈페이지가 새 창으로 열립니다.
③ **문의·연락처는 홈페이지에서** 확인하고 접수합니다.

> 홈페이지가 보이는 회사는 앱 안에서 따로 문의를 접수하지 않습니다. 홈페이지 화면을 앱 안에 그대로 넣을 수는 없어(대부분의 홈페이지가 외부 삽입을 막습니다) 새 창으로 열립니다.

## 5. 공지 — 안내 확인하기

회사·협력사에서 보낸 운행 관련 공지를 모아 봅니다.

① 아래 메뉴에서 **`공지`** 를 누릅니다.
② 공지 목록에서 제목을 눌러 내용을 확인합니다.
③ 안 읽은 공지가 있으면 메뉴에 **빨간 숫자 배지**가 표시됩니다.

![공지 화면](assets/employee/06-notices.png)

> **긴급 공지**는 앱을 열 때 전체 화면으로 떠서 반드시 확인하게 됩니다. **`확인했습니다`** 를 누르면 닫힙니다.

## 6. 설정 — 내 정보와 알림 진단

내 정보 확인, PIN 변경, 알림 점검, 앱 설치를 합니다.

① 아래 메뉴에서 **`설정`** 을 누릅니다.
② **내 정보**에서 이름·사번·부서·배정 노선을 확인합니다.
③ 공지 알림이 안 오면 **알림 진단**의 **`알림 재발급`** 을 누릅니다.
④ 권한 상태가 **거부됨**이면, 브라우저 주소창의 자물쇠 아이콘 → 알림 → **허용**으로 바꾼 뒤 다시 시도합니다.

![직원 설정 화면](assets/employee/08-settings.png)

> **배터리 절전 예외** — 휴대폰 절전 기능이 앱을 잠재우면 공지 알림이 늦게 올 수 있습니다. 삼성 갤럭시는 *설정 → 배터리 → 백그라운드 사용 제한*에서 BusLink를 제외해 주세요. (아이폰은 별도 설정이 필요 없습니다.)
